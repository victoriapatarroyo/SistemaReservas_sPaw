# 🐾 sPaw Reservation System

Full Stack backend application for managing reservation workflows, designed with scalable architecture and best practices in mind.

---

## 🚀 Overview

sPaw is a reservation management system designed to handle business logic, bookings, and service coordination. The project focuses on clean architecture, scalability, and maintainability using modern backend development principles.

This project showcases my experience as a Senior Backend Developer and Tech Lead, applying enterprise-level practices in a real-world scenario.

---

## 🧠 Tech Stack

- Backend: Java, Spring Boot  
- Architecture: Layered Architecture  
- API: RESTful services  
- Database: Relational (configurable)  
- Tools: Git, Maven  

---

## 🏗️ Architecture

- Controller Layer → Handles HTTP requests  
- Service Layer → Business logic  
- Repository Layer → Data access  

✔ Clean separation of concerns  
✔ SOLID principles applied  
✔ Scalable design

## 📂 Project Structure

## ⚙️ Getting Started

### Prerequisites

- Java 8+  
- Maven  

### Installation

1. Clone the repository  
   `git clone https://github.com/victoriapatarroyo/SistemaReservas_sPaw.git`

2. Navigate to the project directory  
   `cd SistemaReservas_sPaw`

3. Build the project  
   `mvn clean install`

4. Run the application  
   `mvn spring-boot:run`
